# tjander3.github.io

Personal homepage for [tjander3](https://github.com/tjander3), designed to be published with GitHub Pages.

## Publish it

1. On GitHub, create a **public** repository named exactly `tjander3.github.io`.
2. Upload the files in this folder to the repository's `main` branch.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.

After GitHub finishes publishing, the site will be available at <https://tjander3.github.io>.
